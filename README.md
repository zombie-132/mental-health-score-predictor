# 🧠 Mental Health Score Predictor

A machine learning-based web application that predicts mental health scores using user-provided information. Built to explore the practical integration of **Machine Learning and Web Development**.

## 🚀 Live Demo

**[View Live Application →](https://mental-health-score-predictor-b1mg.onrender.com/)**

## ✨ Features

- Machine learning-based mental health score prediction.
- Simple and user-friendly interface.
- Data preprocessing and model integration.
- Deployed web application accessible online.

## 🛠️ Tech Stack

- **Language:** Python
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render

## 💻 Run Locally

```bash
git clone https://github.com/zombie-132/mental-health-score-predictor.git
cd mental-health-score-predictor

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

Run the application using the command appropriate for the project's framework.
